# v76 — CSS organizado em `css/src/` — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** dividir `css/styles.css` (2.306 linhas) em 11 arquivos-fonte em `css/src/`, juntados por `tools/montar-css.mjs` num `styles.css` idêntico ao da v75, exceto pelo comentário de cabeçalho.

**Architecture:** os fontes são fatias contínuas do original, na mesma ordem. O script concatena em ordem alfabética, sem separador. Um teste unitário garante que o `styles.css` é a junção exata, e o `bump-version.mjs` passa a gravar a versão no fonte e montar.

**Tech Stack:** Node ≥ 22 (`node:fs`), sem dependências.

**Spec:** `docs/superpowers/specs/2026-11-04-css-fontes-design.md` (seção "v76 — organização")

## Global Constraints

- O `styles.css` publicado continua sendo **um arquivo**; `index.html` e o `SHELL` do `sw.js` não mudam (só o bump de versão).
- Diferença permitida em relação à v75: **apenas** o comentário de cabeçalho (`00-base.css`).
- Nenhuma referência de teste regravada (equivalência, literais).
- Commits em português; antes do `git add`, rodar `git checkout -- artifacts/`; versão final **v76**, sem novidade para o usuário (`data-conteudo` mantém `71`).

## Review Focus

1. **Fatia com uma linha a mais ou a menos** (corte no meio de uma regra, linha em branco duplicada ou perdida): a comparação byte a byte com a v75 da Task 1 pega.
2. **Editar o `styles.css` direto em vez do fonte:** o teste "CSS montado a partir de css/src" falha. A Task 1 prova isso editando o gerado de propósito.
3. **Bump de versão desalinhando fonte e gerado:** a Task 2 começa por um RED real, rodando o bump antigo e vendo o teste falhar.
4. **Final de linha (CRLF) ou BOM** vindos de outro editor quebrariam a junção: o script lê e grava em UTF-8 sem transformar, e o teste compara bytes.
5. **`css/src/` publicado no site:** a Task 2 acrescenta a exclusão no `deploy.yml`, e a revisão confere o rsync.

```js
const resultadoCssMontado = await (async () => {
  try {
    const { montarCSS } = await import(pathToFileURL(join(raiz, 'tools', 'montar-css.mjs')).href);
    return montarCSS(raiz) === readFileSync(join(raiz, 'css', 'styles.css'), 'utf8')
      ? 'CSS MONTADO EM DIA' : ['css/styles.css diferente de css/src/ — rode node tools/montar-css.mjs'];
  } catch (e) { return [`montar-css: ${e.message}`]; }

rodar('CSS montado a partir de css/src', () => resultadoCssMontado);
```
